# Track Score Web App

## Introduction

This project contains a server and client implementation for a SPA (single page application). The
application can be used to track scoring for various games on mobile devices.

The client is implemented using TypeScript and React. The server is implemented using PHP and
CakePHP framework.

A working version of this project can be found at: https://www.trackscore.nl

The client contains most of the implementation. The server implements a simple API to store and
retrieve game session data. This allows the client to share game sessions between multiple devices.
